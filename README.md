# 주식회사 미삭 홈페이지

정적 HTML/CSS/JavaScript 기반의 반응형 홈페이지입니다.

## 페이지
- index.html: 메인 홈
- company.html: 회사소개
- business.html: 사업분야
- equipment.html: 보유 설비
- process.html: 제작공정
- certificates.html: 인증현황
- location.html: 오시는 길

## 배포
GitHub Pages에서 main 브랜치의 루트 폴더를 게시합니다.
홈페이지 파일 수정 후 main 브랜치에 push하면 자동으로 갱신됩니다.

## 로컬 미리보기
이 폴더에서 `python3 -m http.server 8092`를 실행하고 http://localhost:8092 를 엽니다.

내부 검토용 source-notes 폴더는 Git과 배포 대상에서 제외합니다.
